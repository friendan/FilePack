# FilePack
FilePack

直接 7zG.exe a 文件(或文件夹) 会直接开始压缩，不会停在设置界面
要只弹出 “添加到压缩包” 对话框、让你手动选参数、不自动开始，用：
7zG.exe a -ad "C:\要压缩的文件或文件夹"
-ad 就是 “show Add dialog”，只弹界面，不自动压缩。

7zG.exe：带界面的命令行版（进度框、添加对话框）。
7zFM.exe：主界面管理器（双击压缩包打开的那个）。
7z.exe：纯后台命令行，无界面。


7zG.exe 完全支持传多个文件 / 文件夹路径，而且能直接批量塞进「添加到压缩包」图形界面。
正确用法（只弹界面、不自动压缩）
核心参数：-scc 才是唤起手动压缩对话框（不是 -ad，之前那个不对）
7zG.exe -scc "路径1" "路径2" "路径3"
7zG.exe -scc "D:\文档" "D:\照片" "C:\桌面\项目文件夹"
执行后直接弹出 7z 添加压缩包窗口，里面已经自动勾选好你传的所有文件 / 文件夹，不会自动开始压缩，任由你自己选格式、密码、压缩级别、保存路径。

关键说明
多个路径用空格分隔，每个路径带空格就用英文双引号包起来。
不要加 a，加了就会自动后台压缩，不弹窗。
-scc = Show Compress Dialog，专属唤起「添加到压缩包」图形窗口参数。
支持任意多个文件、文件夹混合传入。

可以，既能传多个文件，也能预先填好压缩包路径和名称，再弹出界面让你确认 / 修改。
1. 语法（弹窗 + 预设压缩包名 + 多文件）
cmd
7zG.exe a -ad "D:\输出路径\预设名.7z" "文件1" "文件2" "文件夹3"
7zG.exe a -ad "E:\备份\2026资料.7z" "C:\桌面\项目" "D:\文档\报告.pdf"

之前的 -scc 问题
-scc 是 “仅弹窗、不预设压缩包名”，适合临时压缩。
要预设名称 + 多文件 + 弹窗确认，必须用 a -ad

7-Zip 可以直接打包成标准 tar.gz（Linux 常用格式）
7z a -ttar -tgz 输出.tar.gz 要打包的文件/文件夹
7z a -ttar -tgz "D:\output\test.tar.gz" "D:\mydir"
-ttar：打包为 tar 容器
-tgz：再用 gzip 压缩
7z 还支持：
tar.bz2
tar.xz
tar.zst
都是 Linux 常用格式，命令行换参数就行


7z.exe a -ttar "D:\test.tar" "D:\Debug\11.log"
7z.exe a -tgzip "D:\test.tar.gz" "D:\test.tar"
del "D:\test.tar"
pause
